# Data Dictionary

| Column                      | Description                    |
| --------------------------- | ------------------------------ |
| Activity_Period             | Reporting period               |
| Activity_Period_Start_Date  | Start date of activity period  |
| Operating_Airline           | Airline operating the flight   |
| Operating_Airline_IATA_Code | IATA code of operating airline |
| Published_Airline           | Public airline name            |
| Published_Airline_IATA_Code | IATA code of published airline |
| GEO_Summary                 | Domestic or International      |
| GEO_Region                  | Geographic region              |
| Activity_Type_Code          | Enplaned, Deplaned, or Transit |
| Price_Category_Code         | Fare classification            |
| Terminal                    | Airport terminal               |
| Boarding_Area               | Boarding area designation      |
| Passenger_Count             | Number of passengers           |
| data_as_of                  | Dataset publication date       |
| data_loaded_at              | Data ingestion timestamp       |
